## 月流量 3T 到底是什么概念

3T（3000GB）月流量，平均下来每天 100GB。换算一下就知道这个量级在哪：

- 一个日访问量几千 IP 的个人博客，月流量通常几十 GB，3T 用掉零头都不到
- 跑代理节点、看流媒体，单人使用一个月大概几百 GB，离 3T 还很远
- 真正能吃满 3T 的，是持续下载、备份同步、爬虫抓取、给网盘中转这类“机器在干活”的场景

所以判断自己需要多少流量，先看机器是给人用的还是给程序用的。人用的（博客、面板、轻量服务）3T 有大量富余；程序 24 小时跑的（下载机、备份、中转）才需要认真算。行业里常见的套路是端口给 1Gbps、流量只给 500GB 到 1TB，端口速度再快，流量月底见底也一样歇菜。RackNerd 的思路反过来：限制总流量，端口速度给足，官方 specials 页所有套餐统一 1Gbps。
